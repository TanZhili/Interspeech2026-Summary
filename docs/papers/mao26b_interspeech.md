# Age-Related Changes in Mandarin Lexical Tone Production: Acoustic Properties and Tonal Distinctiveness

- 论文编号：1702
- 报告人：Zhongxuan Mao
- 程序：Thursday 1 October 2026 / Gender- and Age-Related Speech Characteristics
- 技术分类键：phonetics
- 全文：https://www.isca-archive.org/interspeech_2026/mao26b_interspeech.pdf

## 问题
老化对英语等非声调语言的 F0/时长影响已有较多证据，但对普通话声调产出的音高高度、斜率及调类可分性如何变化，以及是否与已知感知困难平行，仍不清楚。

## 方法
78 名南京普通话母语者：年轻组 18–30 岁（n=36）、老年组 55–77 岁（n=42），朗读 236 个覆盖四声的音节。提取说话人归一化 T 值的 t_mean、t_slope、t_SD、t_range、t_onset、t_offset 与时长，用 LMM 检验 Group×Tone×Gender。再用 Bhattacharyya 距离与 RBF-SVM（10 折）评估调类可分性，并以置换重要性比较特征。

## 实验与结果
老年表现出性别分化的 F0 中心化、轮廓变平、F0 变异增大与时长加长，效应因声调与性别而异。年轻组 SVM 准确率 94.35%，老年 84.50%；老年混淆集中在双向 T2↔T3（合计约 36.47%）。多数声调对 BD 随年龄下降，T2–T3 最低。特征重要性上老年更依赖 duration 与 t_SD，年轻更依赖 t_offset 与 t_range。

## 结论
作者认为老化降低声调系统可分性，且与感知研究中 T2–T3 脆弱性平行，支持 auditory-motor integration 模型；声学变化随声调与性别交互，非简单整体抬高/压低 F0。

## 点评
把个体声学参数与类别可分性（BD + SVM）合在一起，比只报均值更有说服力；T2↔T3 产出混淆与既有感知文献形成闭环。老年听力/认知筛查已做，但仍含轻听损与轻度认知下降者，因果上“听觉反馈受损→产出退化”仍属解释性推断。
