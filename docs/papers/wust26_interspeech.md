# Applying the Simplified Vocal Profile Analysis to Swiss German Dialects

- 论文编号：329
- 报告人：Alessia Wüst
- 程序：Tuesday 29 September 2026 / Cross-Linguistic and L2 Phonetic Studies
- 技术分类键：phonetics
- 全文：https://www.isca-archive.org/interspeech_2026/wust26_interspeech.pdf

## 问题
瑞士德语音段研究丰富，但习惯性嗓音/声道设置（vocal profile）缺系统感知编码与地理–社会分布证据。

## 方法
从 Swiss Dialäktatlas 取 127 名 18–40 岁说话人约 1 分钟自发样本；四名编码者用 Simplified Vocal Profile Analysis（SVPA）评声道设置；五次共识会解决分歧；报告 Fleiss’ κ，并做性别与地理分层。

## 实验与结果
个体 IRR 偏低（κ≈0.09–0.39），但共识编码显示清晰分层：男性更常放松声道（hypoarticulation），女性更倾向咽腔扩展（hyperarticulation）；男性低喉位更常见（χ² 显著）。东北部鼻音色彩、中部咽扩展突出（后者可能与样本性别构成混淆）。吱嘎声罕见（约 9%）。多项设置显著高于机遇（p<0.05）。

## 结论
Vocal profile 可作为瑞士德语区域与社会身份标记，但编码协议需 refinement 以提高信度。

## 点评
填补瑞士德语嗓音设置地图空白，社会语音学意义明确。强在共识流程与地理地图；脆弱点在低 κ 与性别–地区混淆，因果解释需后续平衡抽样。
