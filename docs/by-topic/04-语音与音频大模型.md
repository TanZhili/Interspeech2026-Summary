## 技术趋势

### 音频推理：从“答对”到“证据可核验”

Audio Reasoning Challenge（mon-019）把评测重心从答案准确率推到 **MMAR-Rubrics** 下的推理链事实性与逻辑自洽，并分 Single Model 与 Agent 两赛道。Agent 侧普遍把 LALM 当工具或证据源：多源观测、声学工具分层、证据编排与一致性校验；单模型侧则强调大规模推理数据（如 545k）、渐进式 RL 与训练无关的注意力/解码干预。并行的 mon-033 / wed-110 则把同一问题拆成更细的失败模式：**文本语义压制声学证据**、时间定位脆弱、实体绑定失败、多音频输入随路数增加急剧退化。Step-Audio-R1（thu-169）把“越推理越差”诊断为 **textual surrogate reasoning**——模型对着转写式抽象沉思而非声学属性；其 MGRD 框架用自蒸馏与多模态 RL 把推理链重新锚定到声学。

### 幻觉控制与评测可信度

幻觉缓解呈现两条互补路径。训练无关侧：噪声先验 in-context（NAICL）、静音锚定的层加权向量转向（LWVS）、真实音频对静音的 token 自适应对比解码（TAD）、反事实音频证据重打分（CoRE）。训练/蒸馏侧：CAAD 把教师对比解码内化进学生权重，降低推理期对比开销。与之并行的是评测本身的可信度危机：MCQA 对选项顺序与题干改写敏感（波动可达约 24%，甚至改变模型排名）；去掉音频后模型仍可保留约 60–72% 的“满分”，真正需要完整音频片段的题目极少（约 3–4%）。DOWIS、VQ-Bench、IndicContextEval、SHALLOW、StanceBench、PolyBench、INSPIRE、NVV-SuperBench 等基准从发声类型、上下文利用、ASR 幻觉分型、人际姿态、复调推理、指令感知检索、非言语发声等维度，把“高分≠听懂”坐实为可测问题。

### 语音–文本对齐与离散/连续表征

模态鸿沟被多场反复触及。mon-009 把部分推理退化归因于 **时间粒度错配**：语音 token 远长于同义文本，稀释每 token 语义密度；在固定信息率下扫描帧率，摘要给出约 4.17 Hz + 中间层对齐对语音 QA 更有利的区间。HybridCodec、TASTE-Streaming、UniARC 则比较离散/连续/混合编码：离散利于自回归与 LLM 接口，但信息损失损害说话人等属性；混合离散–连续残差、文本对齐流式 tokenization、语义约束的 tokenization 成为主要对策。ALARM 针对推理型 LLM：冻结 LLM 只训适配器时，自生成 CoT 会暴露文本替身输入；自重写与多编码器融合用于恢复“像听音频”的响应分布。thu-167 的混合 batching 显示：即便目标域语音不足全程的约 10%，也能提供强模态对齐信号，使 LLM-ASR 适配接近全量成对微调。

### 自监督表示：可解释性、适配与语音学分析

representation 会场重心已从“把 SSL 做准”转向“说清表示里有什么、如何在约束下用对”。InsideSSL / GRIDS 从熵、曲率、局部本征维数刻画层动力学与扰动几何；WavLM 上的 Hydra 效应说明稀疏神经元消融不够，需子空间级干预。预训练扩展覆盖多采样率、双模式流式、BEST-RQ 伪标签在线精炼；适配侧出现联邦早期退出、Gumbel 硬层选择、可懂度条件化 FiLM、推理期软离散分配。语音学侧用点击辅音细调、音系竞争时间基准、韵律 ABX、次声门共振估计与原始波形错误分析，检验类人增量加工与韵律对比敏感度。wed-143 则把表示问题外延到语系结构、维度独立性、声–脸关联、法医编解码痕迹与低资源语种持续学习。

### 语音基础模型后训练

Special Session thu-169 把后训练做成独立议程：面向深度伪造的 mix-frame 监督后训练、干预对比学习拆分内容/说话人子空间、统一话语级多属性表示、ALLM 细粒度反馈驱动的 TTA 指令跟随、深度上扩把语音层插入冻结文本 LLM、TASU2 可控 CTC 仿真做文本侧对齐课程、知识定位与编辑、Audio-Side Time Prompt + RL 强化时间感知、交错 stacking 加速蒸馏。共同取舍是：在尽量不毁掉预训练能力（尤其文本能力）的前提下，注入任务特异信号、声学 grounding 与时间结构。

### 基准评测与能力边界

Benchmarking Foundation Models（thu-181）与前述评测论文共同表明：基础模型评测正从单一 WER/准确率走向分型、指令条件、副语言与生成可控性。低资源真实场景（TaigiSpeech）与频带可解释性（质量评估网络 vs 人耳）提醒：扩展能力的同时，数据稀缺与模型–人类敏感因素错位仍是部署瓶颈。

## 技术内容

### Monday 28 Sep · 11:00–13:00 · Audio Reasoning Challenge（Challenge，12）

**The Interspeech 2026 Audio Reasoning Challenge: Evaluating Reasoning Process Quality for Audio Reasoning Models and Agents**（论文 118；Ziyang Ma）  
指出 LALM 理解强但推理不透明。挑战以 MMAR-Rubrics 评估推理链事实性与逻辑，设 Single Model 与 Agent 赛道；摘要称吸引 156 队来自 18 个国家/地区，Agent 在推理质量上领先，单模型经 RL 与数据管线快速进步。

**The 5th ISCA-PECRAC Connecting Early Career Researchers and Social Gathering**（无论文编号）  
官方程序未提供摘要；按标题为面向早期职业研究者的 ISCA-PECRAC 交流与社交卫星活动。

**Multi-Source Evidence Fusion for Audio Question Answering**（论文 3297；Aivo Olev）  
TalTech Agent 方案：两路 LALM 独立观测，文本推理模型对照按可靠性分层的约 25 个声学工具输出，使每步锚定可验证证据。摘要称在挑战推理质量指标上排名第一并大幅领先。

**VISA: A Visual Information Strengthened Audio-Reasoning System for the Interspeech 2026 ARC Agent Track**（论文 2381；Wenming Tu）  
在 “LALM as a Tool” 范式下融合多模态特征、模型投票与一致性检查、细粒度类别感知路由。摘要称 Agent Track 总分第二（Rubrics 66.23%），并在两赛道取得最高 Accuracy 77.40%。

**Beyond Symmetric Interaction: Capability-Aware Asymmetric Multi-Agent Collaboration for Audio Deep Reasoning**（论文 2273；Chenxing Li）  
提出 AsymAudio：跨 LALM 互补声学融合、角色自适应非对称策略，以及重采样与自校正的一致性精炼。摘要称 Agent Track 排名第 3。

**EChO-Agent: Evidence Chain Orchestration Agent for Audio Reasoning**（论文 1313；Siyuan Zhang）  
将复杂音频问答重构为规划、工具执行、证据整合与答案验证工作流。在 MMAR 上相对基线提升准确率与 rubric；消融显示证据整合是关键因素。

**Audio-DeepThinker: Progressive Reasoning-Aware Reinforcement Learning for High-Quality Chain-of-Thought Emergence in Audio Language Models**（论文 1720；Chenxing Li）  
用混合推理相似度奖励与两阶段渐进 RL（RL-Zero）促使 CoT 涌现。报告 MMAR 74.0%、MMAU-Test-Mini 78.5%，获 Single Model Track 第 1。

**Audio-Cogito: Towards Deep Audio Reasoning in Large Audio Language Models**（论文 988；Longhao Li）  
开源方案：Cogito-pipe 构建约 545k 推理样本并以自蒸馏微调。在评估 CoT 的 MMAR 上称开源最优，部分指标匹敌或超过闭源；挑战中位居前列。

**MATA: A Training-Free Approach to Mitigate Cross-Modal Attention Imbalance in Large Audio Language Models**（论文 1212；Junyu Wang）  
训练无关地在中间层对末 token 推高对音频 token 的注意力。在 MMAU 与 MMAR 上一致提升；与 Qwen3-Omni-Thinking 结合获 Single Model Track 第 2，摘要称顶尖方案中唯一训练无关方法。

**TAD: Token-Adaptive Contrastive Decoding with Confidence-Guided Gating for Hallucination Mitigation in Large Audio-Language Models**（论文 637；Heyu Chang）  
训练无关对比解码：用真实音频与匹配静音参考对比 logits，并以置信门控调节。相对 AAD，摘要给出 Qwen2 / Gemma 在 AudioCaps-Hallucination 与 Clotho-AQA 上的 F1 提升区间。

**TinyGiantALM: A Compact Audio-Language Model for Intent-Aware Reasoning under Resource Constraints**（论文 491；Vinh-Thuan Ly）  
1.5B 紧凑模型，以 Query-guided Projector 与 Semantic Gating 按用户意图过滤声学。MMAR 零样本准确率 46.4%，显著优于 7B–13B 基线；相对 30B+ 仍有逻辑叙事差距。

**Structured Prompting vs. Self-Training for Audio Reasoning Under Limited Data and Compute: Lessons from Interspeech Audio Reasoning Challenge 2026**（论文 2880；Steven Au）  
在 Qwen3-Omni 30B 上比较结构化提示、DSPy MIPROv2 与 ReST+qLoRA。结构化提示相对基线准确率 +5.5%；ReST 训练相对基线下降。

### Monday 28 Sep · 11:00–13:00 · Speech Representations and Alignment（Long Oral，6）

**Which Speech Representation Better Matches Text-Native Reasoning? A Study of Speech-Text Alignment on Frame Rate and Representation**（论文 21；Zhen Ye）  
将部分语音条件推理退化归因于时间粒度错配。引入 factorized FSQ 与轻量非自回归音频 LM 头，使低帧率可达近 300 bits/frame；在冻结 LLM、固定信息率下扫描 50→2.08 Hz，摘要称语音 QA 在约 4.17 Hz 与中间层表示对齐时表现最佳。

**InsideSSL: Understanding Self-Supervised Speech Representations using a Model-Centric Perspective**（论文 733；Samir Sadok）  
从压缩（熵）、几何（曲率）与扰动鲁棒性做任务无关的层分析，并引入跨层 Generative Compatibility Matrix 评估功能可迁移性。线性探测把层拓扑与音素、音高、说话人编码联系起来。

**Montreal Forced Aligner and the state of speech-to-text alignment in 2026**（论文 2734；Michael McAuliffe）  
综述 MFA 3.0：多语言覆盖、谐调 IPA 词典、适配与跨语言音素重映射等。在英/日/韩四套基准上，摘要称平均边界误差低于 15 ms，达 SOTA 或近 SOTA。

**GRIDS: Dimensionality-Aware Anomaly Detection in Learned Representations of Self-Supervised Speech Models**（论文 2719；Sandra Arcos-Holzinger）  
用局部本征维数（LID）观察 WavLM / wav2vec 2.0 在良性噪声与对抗扰动下的几何形变。LID 升高与 WER 升高共现；层间 LID 特征可做无转写异常监测（AUROC 0.78–1.00）。

**ALARM: Audio–Language Alignment for Reasoning Models**（论文 759；Hassan Shahmohammadi）  
针对推理型 LLM：自重写把自生成响应转为兼容 RLM 的音频理解变体；融合压缩多音频编码器；构建约 6M 实例、约 19K 小时多任务语料。4B ALM 在 MMAU-speech / MMSU 上称开源最佳，并在全模型中排名第三。

**Cross-Attention is Half Explanation in Speech-to-Text Models**（论文 40；Luisa Bentivogli）  
比较 S2T 交叉注意力与特征归因显著性。注意力与显著性中等对齐，但交叉注意力大约只捕获约 50% 的输入相关性、至多约 52–75% 的编码器显著性，不宜单独当作行为解释。

### Monday 28 Sep · 14:30–16:30 · Reasoning with Speech/Audio Language Models（Poster，10）

**Beyond Semantic Dominance: Cognitive Affective Reasoning and Empathetic Response Alignment in Audio Language Models**（论文 2400；Zhixian Zhao）  
ALM 文本语义常压制声学细节。CogAudio-LLM 构建 LIME-440K，引入四步 CoT（EIPS），经多阶段训练蒸馏为隐式生成，并用 DR-SAPO 平衡逻辑与共情回复。

**Towards Deep Contextual Reasoning from Broad Descriptions for ASR with Speech-LLM via Metadata-Driven Reasoning Chains**（论文 1041；Jakob Poncelet）  
用视频等宽泛描述作弱语义先验，构造约 400 小时推理增强数据：先假设转写、再上下文推理、最后校正。摘要称在留出 YouTube 衍生测试集上降低稀有词与命名实体错误。

**Entity Binding Failures in Speech LLM Reasoning: Diagnosis and Chain-of-Thought Intervention**（论文 640；Ming-Hao Hsu）  
诊断需实体追踪的逻辑任务跌至机遇水平为 entity binding failure。EA-CoT 在推理前枚举实体并绑定到命题；摘要称即使口语姓名识别有误也可弥合差距。

**Breaking Neutral Bias: Zero-Human-Annotation Fine-Grained Emotion Enrichment via Semantic Drift and Discriminative Re-ranking**（论文 1925；Qihang Lu）  
用 LLM 多维语义漂移探索情感假设，再用判别式 judge 经 hard-negative contrastive learning 按原始声学过滤，避免纯文本增强引入声学幻觉。

**AudioGround: Fine-Grained Temporal Grounding in Audio via Deterministic Boundary Supervision**（论文 3467；Mingi Kim）  
AudioGround-IT 提供确定性边界监督；AudioGround 扩展 SALMONN，用滑动窗口 Q-Former 与时间戳条件。摘要称在多项时间定位基准上显著优于先前 LALM。

**A Closer Look at Failure Modes in Temporal Understanding of Large Audio-Language Models**（论文 3070；Apoorva Kulkarni）  
提出含三类基础任务的分析型时间基准。行为分析显示有文本线索时模型常低利用音频；因果机制分析表明跨音频 token 重分配注意力优于单纯放大音频注意力。

**Noise-Aware In-Context Learning for Hallucination Mitigation in ALLMs**（论文 1610；Qixuan Huang）  
NAICL 构建噪声先验库并检索相关噪声样例作上下文；同时建立 Clotho-1K 幻觉基准与四类听觉幻觉细粒度指标。摘要报告幻觉率下降。

**Silence is Golden: Mitigating Hallucinations in Large Audio-Language Models via Layer-Weighted Vector Steering**（论文 1421；Tsung-En Lin）  
以主动音频对静音基线做对比向量转向，并据层表征与正确性相关提出 LWVS。摘要报告 Audio Hallucination QA 上 Recall 提升，并在 MMAU 上保持乃至增强通用理解。

**CoRE: Contrastive Evidence-Aware Rescoring for Multiple-Choice Audio Question Answering**（论文 656；Yiqiang Cai）  
训练无关：用块置换与随机段反转构造反事实音频，估计选项证据增益并自适应门控。摘要称在 DCASE 2025 Task 5 与 AIR-Bench SoundQA 上对 Qwen2-Audio、Kimi-Audio 有一致增益。

**Search-GRT: Guided Retrieval Training of Search Agents to Optimize for Complex Question Answering**（论文 2006；Aounon Kumar）  
官方标题如此，但摘要论述流式多说话人 ASR 四类架构策略（diarization 与 ASR 整合方式）及部署约束下的选型。本条仅据摘要正文归纳。

### Monday 28 Sep · 14:30–16:30 · From Self-Supervised Pre-training to Phonetic Analysis of Speech Models（Poster，11）

**MSR-HuBERT: Self-supervised Pre-training for Adaptation to Multiple Sampling Rates**（论文 1354；Zikang Huang）  
用 multi-sampling-rate adaptive downsampling CNN 把不同采样率波形映射到共享时间分辨率。摘要称在 16–48 kHz 实验中优于 HuBERT，并保留掩码预测目标以便复用分析。

**Online Predictive Coding for Dual-Mode Self-Supervised Speech Models**（论文 1997；Keita Goto）  
对 online registers 做多步未来预测正则，并加入 Dual-mode Layer Normalization。摘要称 OPC 缩小在线–离线差距，并给出约 160 ms 延迟下的 WER 变化。

**Enhancing BEST-RQ Pseudo-Label Quality Through Online Refinement for Automatic Speech Recognition**（论文 650；Jingjing Xu）  
将量化器线性投影换 PCA、迭代码本精炼与 codebook distillation。在 Librispeech 960h 预训练、100h 细调设置下，三项全开时摘要报告 test-other 相对 WER 下降。

**IACC-HuBERT: Intelligibility-Aware Channel Conditioning of HuBERT Frontend for Dysarthric Speech Conformer ASR**（论文 2375；Hemant Kumar Kathania）  
用 FiLM-only / Gated-FiLM 按说话人可懂度调制 HuBERT 特征，仅训练少量参数接入 Conformer ASR。摘要给出相应 WER，强调可懂度感知通道条件化。

**ZipCodec: Simple and Pretrained-Model-Free Speech Tokenizer via Flow-Matching**（论文 2941；Lingxuan Ye）

在指定 WER 区间仿真 CTC 后验，使纯文本监督更贴近声学解码接口。摘要称跨多源→目标适配设置优于 TASU、纯文本细调与 TTS 增强，并减轻源域退化。

**Adapting Text LLMs to Speech via Multimodal Depth Up-Scaling**（论文 2099；Kazuki Yano）  
向冻结文本 LLM 插入新 Transformer / E-Branchformer 层并仅训练新增层。摘要称 ASR 可比全量细调，文本能力退化远小于全量细调与 LoRA；更大模型上文本退化降逾 75%，可训参数少约 60%。

**Localizing and Editing Knowledge in Large Audio-Language Models**（论文 2066；Jiaheng Dong）  
构建首个面向 LALM 事实定位与编辑的音频基准；语音感知因果追踪定位后编辑。摘要称事实知识联合编码于音频编码器与语言骨干，音频侧编辑优于文本编辑或细调。

**Towards Fine-Grained Temporal Perception: Post-Training Large Audio-Language Models with Audio-Side Time Prompt**（论文 745；Yanfeng Shi）  
把时间戳编码为嵌入并交错进音频特征序列；SFT 后接 RL（TimePro-RL）直接优化时间对齐。摘要称在 grounding、声音事件检测与稠密音频描述等任务上显著增益。

**Fast Speech Foundation Model Distillation Using Interleaved Stacking**（论文 3071；Eungbeom Kim）  
交错 stacking 在加深过程中保持层位置一致，以加速 SFM 蒸馏同时缓解既有 stacking 的性能下降。在 SUPERB 上验证有效性。

**TaigiSpeech: A Low-Resource Real-World Speech Intent Dataset with Scalable Data Mining In-the-Wild**（论文 1511；Kai-Wei Chang）  
台湾闽南语真实意图数据集：21 名老年说话人、约 3k 话语，面向医疗与家庭助手。探索关键词匹配 + LLM 伪标注，以及弱文本监督的音视频挖掘；将以 CC BY 4.0 发布。

**Hallucination Benchmark for Speech Foundation Models**（论文 2347；Alkis Koudounas）  
SHALLOW 从词汇、语音、形态、语义四维刻画 ASR 幻觉，并提供分型指标。高质量识别时与 WER 强相关，WER 升高后相关退化，暴露聚合指标掩盖的细粒度错误。

**INSPIRE: A Benchmark for Instruction-Aware Speech Retrieval**（论文 1026；Chen-An Li）  
自然语言指令动态指定相关性准则（语义、说话人、风格、环境声及其组合）。评估 LALM、级联、SSL、对比音频–语言模型四范式；摘要称无一方法稳健覆盖全部意图。

**StanceBench: A Benchmark for Audio LLM-Based Interpersonal Stance Evaluation from Speech**（论文 2938；Yuzhe Wang）  
基于 Seamless Interaction，定义 9 维人际姿态，并报告 LLM-as-a-judge 的稳健性、偏差与姿态推断。摘要称共情/礼貌最易，诚实最难且提示顺序偏差高，交互姿态更依赖语境。

**NVV-SuperBench: Beyond Words, Beyond Quality—Benchmarking Nonverbal Vocalizations in Speech Generation**（论文 2513；Liumeng Xue）  
英/中双语、45 类 NVV 统一分类与多轴协议，评测可控性、放置与感知显著性。15 个系统上，NVV 可控性常与语音质量解耦；低 SNR 口腔线索与长时情感 NVV 仍是瓶颈。

**How Frequency Band Importance Affects Neural Network Predictions and Human Perception for Speech Quality Assessment**（论文 2382；Ada Lamba）  
用 SHAP、偏依赖与扰动分析三款质量评估网络的关键频带，并做人听对比。摘要称网络与人类都对有害因素更敏感，且网络聚焦低频等较小输入片段。

## 跨会场判断

1. **推理质量与评测协议已成主轴，而不是附属指标。** ARC（mon-019）用 MMAR-Rubrics 评过程；mon-033 / wed-110 / thu-169 从失败模式、位置偏差、文本先验、复调组合推理等多点夹击“高分幻觉”。若只看 MMAU 类准确率，会系统高估听觉理解。

2. **声学 grounding 是贯穿 audio-llm 与 representation 的共同瓶颈。** 一边是 CoT / Agent / RL 试图把推理钉回音频（MATA、TAD、LWVS、MGRD、CAAD、Audio-Side Time Prompt）；另一边是帧率对齐、交叉注意力解释力上限、连续 vs 离散信息损失、话语级语义对齐。两边其实在回答同一问题：模型“听”到的是声学，还是文本替身？

3. **自监督底座未退场，但研究问题已换代。** mon-032 / wed-099 / mon-009 显示 SSL 仍是通用前端，工作重心转到层几何、伪标签质量、流式/多采样率、联邦与低资源层选择、韵律/音系可测性。后训练专场（thu-169）则把 SSL/基础模型当作可干预对象：伪造敏感、子空间分解、知识编辑、深度上扩。

4. **对齐与适配手段高度参数高效、且常训练无关。** LoRA/aLoRA 时间戳、深度上扩、TASU2 文本侧 CTC 仿真、提示学习 ZEBRA、隐状态转向、置换自洽、嵌入转向工具检索——共同假设是基座能力可用，缺的是接口、课程与推理期约束。

5. **系统集成线（thu-167）与“纯推理/表示”会场互补。** 时间戳、多说话人 diarization、视频纠错、有限语音域适配、声画离屏说话人等，说明 Speech LLM 正在进入可部署的多模态管线，而不只是基准榜单模型。

6. **评测资产本身成为一等公民。** DOWIS、VQ-Bench、IndicContextEval、Audio2Tool、MUGEN、PolyBench、SHALLOW、INSPIRE、StanceBench、NVV-SuperBench、TaigiSpeech、S3Bench 等表明：2026 年该主题的论文密度，很大一部分花在“如何测对”而非“再刷一个点”。

7. **阅读时需警惕标题–摘要不一致。** mon-033 条目 2006 标题为检索智能体，摘要实为流式多说话人 ASR；mon-019 含无摘要卫星活动。引用与跨会场比较应以摘要正文为准。
