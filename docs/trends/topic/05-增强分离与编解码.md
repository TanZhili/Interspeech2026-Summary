# 语音增强、分离与神经编解码：技术趋势

本组约百余篇工作覆盖单通道/多通道增强、去混响与超分、说话人分离与目标说话人提取（TSE）、神经语音/音频编解码，以及回声消除、主动噪声控制、丢包隐藏等通信与可穿戴前端。总体脉络是：生成式建模（尤其 flow matching 与 Schrödinger Bridge）在感知质量上持续挤压传统回归增强；条件从浅层噪声谱转向 SSL、谐波结构、文本与说话人先验；部署侧则把少步采样、流式延迟旋钮与边缘蒸馏写成一等公民问题。编解码器则越来越像“给语音大模型用的分词器”，低码率之外强调语义–声学解耦与可变时间分辨率。

### 生成式增强：从频谱回归到流形传输

判别式时频映射与掩蔽仍是强基线，但大量新工作把增强重述为噪声条件到干净语音分布的传输：条件 flow matching、整流流、扩散分数匹配与 Schrödinger Bridge 并存。生成目标从 Mel/复 STFT 扩展到 SSL 声学层、离散神经编解码 token，乃至潜空间漂移场。与“堆更大 U-Net”相比，更常见的是用速度对比、表示对齐、可学习桥接初态或去掉冗余时间嵌入等机制，把轨迹拉回干净流形，并追求单步或极少函数评估的推理。感知类指标往往领先，而波形保真、说话人相似与下游字错误率未必同步占优——生成路线与判别路线的指标张力被多篇总结反复点出。

### 条件与表示：解耦、结构先验与轻量注入

条件设计本身成为主战场。一类路线显式解耦语义与音色（或在 SSL 高低层分别取语音条件与声学生成目标），避免在缠绕声学域上“抑噪伤音色、保音色留噪声”。另一类避开脆弱语义提取，改用谐波掩码、基频软定位等物理启发结构先验，在重噪与混响下更稳。第三类把冻结 wav2vec / WavLM 等特征经 FiLM、瓶颈调制或逐层注入接到既有扩散/回归骨干，强调“注入位置与时序压缩”而非换表示域。个性化增强则用干净嵌入分布的 GMM 先验匹配替代干净注册音，降低部署门槛。共性判断是：浅层噪声特征不够、高层语义又可能循环依赖，需要在结构、SSL 与说话人先验之间做任务适配。

### 幻觉、可懂度与后训练第三条轴

生成式增强的短板集中在幻觉、过抑与内容失真。对策包括延迟文本/音素感知条件、dry（去混响）训练目标、重要性码本加权、工作室级声学模块与低幻觉语义前端的级联，以及在离散 token 上做吸收扩散或 Hydra 式骨干替换。编解码相关增强进一步拆开“VQ 作分类目标”与“VQ 作干净先验正则”：连续潜空间回归加码本约束，往往比硬离散分类更稳。面向 SE 语言模型的工作则引入复合感知奖励的策略优化后训练，把架构与数据之外的第三条提升轴写进增强流水线；多任务 decoder-only 框架用任务 token 统一增强、超分、TSE 与分离，但全句条件与自回归解码仍约束严格流式场景。

### 无干净参考、无监督与真实域适配

成对合成数据与真实部署域差仍是核心痛点。无监督 GAN 用双分支显式建模噪声汇、多尺度判别与对齐的环境噪声先验，以抑制源泄漏；也有漂移模型在完全 unpaired 设定下用分布平衡与 SSL 语义距离做单步生成。目标域往往只有噪声加转写：用可切换增强/ASR 模式与冻结识别器 CTC，可在无干净参考下做感知质量与 ASR 友好之间的折中。去混响侧则蒸馏信号处理算法、或用再混响自构造监督，把物理重建思想接进神经模型。引导条件侧，噪声嵌入经先验匹配再注入，比直接用噪声注册更抗域移。整体上，“易采监督信号”（转写、环境噪声、SSL、经典 SPD）正在系统替代难采的干净对齐波形。

### 少步、流式与边缘：延迟成为可配置量

实时与助听约束推动骨干与系统共同压缩。全因果 Mamba/SSM、半帧率自适应算子、渐进知识蒸馏与皮肤加速度计等弱多模态 FiLM，把质量–算力折中推到 MCU 与超低延迟双耳链路。延迟不再只等于换模型：非对称时域 padding、共享骨干加轻量延迟适配器、双缓冲与选择性状态更新，使训练期或运行期可扫延迟–质量曲线。时域神经 AGC、会议场景联合响度控制、以及重建–抑噪不对称损失的单一权衡旋钮，则把“听得见、不失真、下游可用”写成可调目标。阵列侧出现几何感知动态卷积、分布式滤波、空间上采样与伪空间嵌入迁移，强调跨设备与少麦克近似全阵 oracle。

### 分离与 TSE：线索可组合、选择与提取解耦

单通道分离继续在时频双路径上细化局部–全局注意力、稀疏专家与难例课程采样；多通道与在线场景则叠加 diarization attractor、区域扫描、点引导空间条件与本机声消除等产品向目标。TSE 的重心从“换一个更强分离网”转向线索体系：开源模块化框架把注册音、视觉、文本等线索粒度与缺失可用性放进同一配置；音视频工作把唇动映成离散语义 token、用 viseme 轻量前端，或把视觉降级为“只负责选人”的插头，以免噪声 AV 监督拖垮声学先验。生成式 TSE 引入一步 mean-flow、粗到细语言模型与偏好优化；真实人机对话评测则显示极短唤醒注册下感知–识别鸿沟仍大，生成修谱易伤音素。脑电、HRTF 方向与波束交叉注意等，把可穿戴与空间听闻推进到多说话人选择性收听。

### 神经编解码：低码率、解耦与给大模型用的时间轴

编解码工作密集围绕超低码率流式重建：浊清驱动量化、噪声嵌入空间适配、内容优先上下文、ASR 引导统一量化、伪量化级协同省比特等，都在“先保住可懂消息”的通信原则下权衡听感。面向合成与语音 LM 的另一条线强调语义–声学（及说话人、音高、韵律）解耦、多流残差、全局说话人 token，以及极端时间压缩与内容自适应动态帧率，把瓶颈从码率显式转到帧率×自回归步数。声调语的音高残差适配、多采样率统一权重、Schrödinger Bridge 互通窄带与宽带端点，体现部署与互通诉求。评价上开始把表示稳定性（扰动下 token 几何漂移）从重建质量中拆出，提醒高保真不等于下游可用的稳定离散序列；谐波感知残差分带与可变帧掩码等训练期技巧，则试图在不改推理架构的前提下改善分层丢弃与总码率匹配。

### 通用恢复、通信前端与“干净语音”再定义

带宽扩展与超分大量采用流匹配、Vocos 式任意率频谱补全或 MDCT 统一建模，并与抑噪联合的噪声鲁棒 BWE 形成交叉。去混响与 RIR 估计强调跨房间几何迁移、以及“去混响网络暗中编码 RIR”的分析性洞见。全双工回声与噪声、混合扩散音质增强、因果丢包隐藏、个人声区与主动建设性干扰等，把增强边界扩到通话与空间音频产品栈。综述视角则把单通道增强史梳理为时频→时域、回归/分类→生成→基础模型复用，并提示评估协议与“干净语音”定义需随生成式目标一并重审。组内少数睡眠声事件、鼾声度量学习等工作与主线弱相关，更多说明“增强/编解码”标签下仍混有邻近音频前端问题。

综合看，Interspeech 2026 在该方向的共识不是单一骨干胜出，而是三条并行收紧：(1) 生成传输 + 可靠条件（SSL/结构/文本/说话人）换感知质量；(2) 线索可组合的选择性收听与音视频解耦；(3) 编解码作为 LM 分词器的低帧率解耦设计。尚未闭合的问题同样清晰：幻觉与 ASR 友好、真实域无干净参考、严格因果下的一步生成上限，以及 token 稳定性与重建指标的系统性错位。
