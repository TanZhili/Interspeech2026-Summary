# 全双工、轮替与口语对话：技术趋势评论

本组约四十九篇工作覆盖全双工语音交互、轮替与附和、共情与协同、口语对话系统以及口语语言理解。整体不再把“对话”等同于问答流水线，而是把**何时开口、对谁说话、如何听懂、如何共情对齐**一并纳入可建模、可评测的问题。

### 全双工：从能重叠说话到语义与多模态仍对齐

端到端全双工语音模型已能学打断、重叠等自然轮次，但相对文本 LLM 的语义能力仍明显回落。一类做法把文本引导下沉到**轮级**文本–语音交错，而不是在双通道连续音频里做帧级硬插入，以在保留时序流畅的同时迁入语义；另一类则把面部等离散 token 流与音频同帧率接入全双工骨干，扩展到音画同步生成。共性边界是：自由运行下的对齐质量、评测仍偏语义分或离线对话续写，以及真实打断延迟与重叠自然度覆盖不足。级联系统一侧则出现互补路线——用固定视界的**端点预判**做投机执行，掩蔽 ASR→LLM→TTS 串行延迟，并把“实现的前瞻”与“过早触发浪费算力”拆成可调曲线，而不是只报单一精确率。

### 轮替：从静音启发式到“说还是沉默”的上下文决策

多人场景下，暂停含义模糊，二元静音/句末启发式容易把每次停顿都当成发言邀请。趋势是把任务重定义为在完整上下文下对目标角色做 **SPEAK/SILENT**（或 Maintain / Stop & Listen / Takeover / Dismiss 等宏观动作）的决策，并显式监督“该沉默”的类别；零样本 LLM 常接近随机或强 SPEAK 偏置，需要监督微调甚至推理痕迹蒸馏。评测上出现分层诊断：先看动作对不对，再用语义错配率暴露“动作碰巧对了、意图却错了”。角色条件进一步进入实时多人语音代理——同一声学流上，助手是被动听者还是主动主持，应改变抢轮策略。会议与野生视听设定则强调：文本上下文已携带强下一说话人线索，多模态 LLM 尚难充分兑现原始音视频收益；单麦单相机下的说话人感知未来语音活动预测，比依赖复杂麦阵更贴近部署。

### 附和与预判：功能类别、语用合适性与“假懂反馈”

附和不再只是“停顿就插一声”。功能类别相对机会点的延迟不同，快路径（如延续确认）与慢路径（评注、阐述等）在结构上拆开，可减轻单路径多任务互相干扰。流式附和则强调零前瞻：停顿感知的声学软缩放叠加部分 ASR 文本，抑制“问题/指令后需要回答的停顿”上的语用不当附和，并用专门指标刻画非打断目标。与此同时，表面肯定反馈未必等于理解完成——声学动态偏低、中性头姿、话题结构线索可系统区分不一致附和，对 grounding 诊断有直接价值。生成式双通道预训练再接到显式轮次信号（EOT/HOLD/BC 等）时，附和能力往往依赖预训练表征，但精度仍可能偏低，不宜单独作触发器。轻量端点检测的消融亦提醒：在部分电话对话域，声学加韵律已够用，逐帧塞文本反而抬高误触发——“多模态”未必等于“每帧都加文本”。

### 主动介入、上下文遵从与交互质量

评测轴从反应式问答扩展到主动范式：隐式意图与工具调用、潜伏话题监控、口头与数字上下文矛盾纠错、环境声触发等。常见病症是过触发，以及“决定是否说话”与“执行什么任务”之间的落差；链式推理有帮助，但校准比单纯放大模型更急迫。多轮口语系统的失败也不全是“忘记历史”——内部注意力可能已觉察关键轮次，解码却被参数先验压过；推理期对比放大相关上下文分布，可在无再训条件下抬升记忆与自洽子任务，且整段历史当键往往不如精确选轮。系统无关的交互质量建模则尝试用声学、文本与时间特征逼近日志依赖特征，端到端微调后差距缩小，但静态管道与噪声、标签偏斜仍限制声学嵌入收益。噪声环境下合成回复的语言复杂度上，自动与人类转写证据收敛于：应保持自然语法完整句，而非电报式过度简化。

### 共情、协同与对话中的情感动态

共情语音 LLM 从“识别对了情绪”推进到**回复情绪方向与用户一致**；对比式思维链（中性回复 vs 经情感反应与探索修订）把一致性变成可监督目标，但也依赖文本教师造监督与 LLM 裁判。另一路线显式输出 token 级情绪轨迹再条件合成，或把韵律先翻译成自然语言再交给可插拔知识工具，以换取可解释控制，代价是级联误差。对话情感识别侧，不确定性监督按话语自适应抑噪模态，以及把说话人内惯性与说话人间传染拆成双通路图，都在强化“谁影响谁、哪路模态可信”。协同与 entrainment 工作则表明：发音器官协同复杂度可随会话上升并与会话成功相关；半自发多语场景存在声学–韵律对齐与跨语特有的语义→声学两阶段迹象；面对面收敛在参数上是选择性的（韵律易对齐、舌体运动最弱）；数字代理嵌入多人场时，人–人局部对齐强、人–机局部对齐弱。双人协作中，极少量计时交互特征（重叠、话轮切换、说话不平衡）对认知负荷回归可提供互补甚至主导信号——测的是负荷还是任务诱发的轮替模式，仍需拆解。

### Speech LLM、口音与野生交互中的能力对齐

端到端 Speech LLM 相对同系文本模型在复杂指令与推理上仍掉点；跨模态 on-policy 蒸馏让学生在自身轨迹上接受文本教师的 token 级优势，比静态离线蒸馏更贴暴露偏差，并减轻遗忘，但对合成平行性与师生容量匹配敏感。联络中心 ASR 需要压缩对话上下文与关键词投影，而非把原始长历史塞进提示；第一人称“是否在对我说话”则依赖日记化身份、多轮语义与注视先验，出镜外场景尤为关键。口音自适应可提升信任，但错误适配有害，置信门控回退是必要安全阀。阿拉伯语等野生口语–LLM 数据开始把 like/dislike、可答性与金标转写绑在一起，以便拆开 ASR 诱发失败与固有不可答。流式多模态规划与视觉锚定的音频描述通信，则分别服务在线机器人确认与零训练 AVQA，共同点是：级联自然语言接口可绕开昂贵联合训练，但误差会沿链路传播。

### 口语语言理解：多意图、多说话人与“听出来”的消歧

SLU 基准从饱和单意图转向车舱多意图、拒识与统一 LLM/LALM 协议；上下文学习远逊域内微调，端到端可规避 ASR 传播但严格字符串匹配可能低估语义正确性。多说话人理解基准把身份绑定、关系与交互做成诊断式选择题，时间定位与说话人归因是主要瓶颈——更强模型常从“不会答”转为“答错人”。普通话语音消歧数据把多音字、停顿切分与重音焦点做成听音频二选一释义任务，现有大语音模型对停顿/多音字有一定能力，对细粒度重音仍远弱于人。意图侧则出现结构化拒斥推理作训练期正则、原型感知对比与粗到细融合、以及帧级自洽后处理以稳住多意图槽帧；音频推理上，用终局语义“播种”早期潜状态可缓解显式长思维链把注意力拽离音频的问题。口语对话状态跟踪把文本侧的增量编辑与强化学习迁到端到端，并用未配对文本联合训练缓解跨域槽数据稀缺；部署时自预测上一状态的误差传播仍是主瓶颈。表示层面的选择性能力擦除则提醒：仅压低意图边缘概率不够，还需削弱意图–槽绑定以免强制前缀恢复槽结构。长音频时间锚点插入则表明，时间感知是另一类“理解何时发生”的口语能力，与传统槽填充互补。

### 横切结论

若用一句话概括本组趋势：**交互控制（轮替、附和、主动介入）正从启发式计时升格为上下文与角色条件的决策问题；语义与共情能力正通过蒸馏、解码干预与显式情绪/韵律规划向语音侧回流；评测则从单一准确率转向可拆误差源、可诊断错配、可贴部署延迟–浪费折中的协议。** 仍普遍脆弱的是合成/脚本数据与真实噪声多方场景的落差、级联与教师–裁判偏置，以及全双工自由运行下语义、时序与多模态同步的联合达标。
