Abstract
Audio editing aims to modify sound content while maintain-
ing its acoustic context. However, few studies have addressed
temporal audio editing with precise control of event timing. We
propose edit the moment, keep the rest (EMKR), an instruction-
driven framework built on Stable Audio Open that supports
adding, removing, replacing, moving, and extending. EMKR is
trained with a temporal editing pipeline that constructs triplets
(instruction, input audio, target audio), where the instruction
carries information about when to edit. It further incorporates an
explicit edit interval for precise timing and a source-event mask
that preserves the original event instance in moving and extend-
ing. Experiments on mixtures from real-world datasets show
that EMKR enables time-localized editing of polyphonic au-
dio with 100 ms precision while preserving non-edited regions.
This temporal control enables timing-critical editing tasks in
polyphonic mixtures. Audio samples are available online.1
Index Terms: text-guided audio editing, temporal audio edit-
ing, diffusion models
1. Introduction
Diffusion models have substantially improved text-to-audio
(TTA) synthesis, enabling high-fidelity, diverse generation from
natural language prompts across broader audio types and usage
scenarios [1–7]. Beyond basic prompting, several models intro-
duce structured conditioning, including timestamp-based con-
trols, event-occurrence frequency, and frame-level acoustic cues
such as pitch and energy, allowing users to control when events
occur and how they sound [8–11]. These advances have also in-
spired diffusion-based approaches for text-guided audio editing.
Audio editing modifies an existing audio clip according
to user-provided conditions rather than generating audio from
scratch. Recent studies have proposed instruction-guided diffu-
sion models that support tasks such asadding,removing, and
replacing[12–14], as well as methods that enable semantic ma-
nipulation of audio content through exemplar-based reference
signals [15] or audio-language representations [16–18]. While
these methods allow fine-grained control over audio content,
they typically perform coarse-grained temporal editing, where
edits are applied at an unspecified temporal location. This limi-
tation becomes particularly evident in polyphonic soundscapes,
where the same sound class may occur multiple times at differ-
ent moments. In such scenarios, users often need fine-grained
temporal editing that modifies only a specific occurrence with-
out affecting other instances of the same sound event.
Although several studies attempt to incorporate temporal

duce some form of temporal guidance, their ability to control
the precise temporal position of a specific event instance re-
mains limited. As a result, achieving truly fine-grained temporal
editing in polyphonic mixtures remains challenging.
In this paper, we propose edit the moment, keep the rest
(EMKR), an end-to-end, instruction-based framework for time-
localized audio editing in polyphonic mixtures built on Stable
Audio Open (SAO) [4]. EMKR supportsadding,removing,re-
placing,moving, andextendingwithin a user-specified time in-
terval while preserving the rest of the mixture. To enable fine-
grained instance-level temporal editing, EMKR conditions on
both the natural language instruction and the pair of reference
and edit intervals, allowing the model to select the target event
instance and restrict the edit to the desired time span. In particu-
lar,movingandextendingrequire modifying the temporal posi-
tion or duration of a specific foreground event while preserving
its acoustic identity and the surrounding background, making
them preservation-critical tasks. To address this challenge, we
introduce source-event masking (SEM) in the latent representa-
tion to better preserve the source event and prevent unintended
modifications to the rest of the mixture.
2. Method
In this section, we describe EMKR, an instruction-driven diffu-
sion framework for time-localized audio editing in polyphonic
mixtures. Given an input audio clip and a natural language edit-
ing instruction, EMKR generates an edited audio clip that mod-
ifies only the specified event while preserving the rest of the
mixture. We define five editing tasks:adding,removing,replac-
ing,moving, andextending, and train EMKR end-to-end on syn-
thetic triplets that simulate these tasks with precise timing.
Our framework builds on the SAO architecture [4], which
combines a variational autoencoder (V AE) that encodes au-
dio waveforms into latent sequences, a T5-based text en-
coder [23] that embeds the instruction, and a diffusion trans-
former (DiT) [24] that performs text-conditioned denoising in
the latent domain. We augment this backbone with interval-
based timing conditioning, which indicates when an edit should
occur, and the SEM, which explicitly marks the event instance

2.1. Temporal Editing Tasks and Data
Unlike SAO, which conditions on two global timing scalars,
seconds startandseconds total, indicating only the
start time and duration of the generated audio, EMKR uses four
temporal indicators specifying where to edit. Each training ex-
ample is a triplet(x, x∗, y), wherexis the input audio,x ∗ is the
edited target, andyis a natural language instruction. To explic-
itly represent temporal information, each instruction is accom-
panied by structured metadata consisting of a reference interval
R= [r s, re]and an edit intervalE= [e s, ee]. Here,r s,r e,e s,
ande e denote the start and end timestamps of the reference and
edit intervals, respectively (Figure 1). In other words,Ridenti-
fies the region inxto be modified, whileEspecifies where the
resulting edits should appear or disappear withinx∗.
During training, we generate these triplets online rather
than precomputing a fixed dataset. For each sample, we first
draw a background clipb∼ B, which provides the ambient
scene and is shared by the input and target audio. We then draw
a foreground clipf∼Fand an instruction templatei∼I. De-
pending on the task, we mixfwithbat specified time intervals
to obtain the input audioxand the edited targetx ∗, simulating
the effect of applying the desired edit betweenRandE. Finally,
we fill the templateiwith the sampled events and intervals (for
example, “Add a dog barking between 4.0 s and 4.5 s”) to ob-
tain the instructiony, so that the instruction explicitly includes
timing information. We instantiate each editing task under this
formulation as follows:
•Adding:Construct a clean inputx=band set the edit inter-
valEto match the reference intervalR. Obtainx ∗ by mixing
fintobwithinE.
•Removing:Constructxas a mixture ofband multiple in-
stances off. Select one instance with intervalRand obtain
x∗ by removing it withinE.
•Replacing:Constructxas a mixture ofband multiple in-
stances off. Select one instance with intervalRand obtain
x∗ by replacing it withinEwith a foreground clip of a dif-
ferent class.
•Moving:Constructxas a mixture ofband multiple instances
off. Select the source instance to move with intervalR, sam-
ple a destination intervalEthat does not overlap withR, and
obtainx∗ by removing it fromRand inserting it intoE.
•Extending:Constructxas a mixture ofband multiple in-
stances off. Select one instance to extend with intervalR,
sample an edit intervalEsuch thatR⊆E, and obtainx ∗ by
extending it to coverEwhile keeping the original segment
withinRunchanged.

2.1.1. Interval-based Timing Conditioning
Each temporal scalarr s,r e,e s, ande e is mapped through a tem-
poral embedding layer to a 768-dimensional embedding, pro-
ducing four embeddings that are injected into the DiT through
two paths. First, we append the four temporal embeddings to
the T5 text embedding sequence as additional tokens that par-
ticipate in cross-attention. This allows the model to jointly at-
tend to the instruction and the two intervals for consistent tem-
poral control across all five tasks. Second, we concatenate the
four temporal embeddings into a single 3,072-dimensional vec-
tor and project it with a multilayer perceptron (MLP). The pro-
jected vector is added to the diffusion timestep embedding and
appended as a temporal conditioning token to the DiT input.
2.1.2. Source-Event Masking
Themovingtask relocates a source event while preserving its
acoustic content, whereasextendingkeeps the original segment
and generates a coherent continuation beyondRwithout alter-
ing other events or the background. To provide an explicit cue
for the source instance, we introduce the SEMm src. The mask
is 1 on the reference intervalRand 0 elsewhere. Letz 0 de-
note the clean V AE latent of the input mixture andz t denote
its noised version at diffusion stept. We form the DiT input by
concatenatingz t,z 0, andm src along the channel dimension and
projecting the result with an MLP. The SEM is activated only
formovingandextendingand set to zero foradding,removing,
andreplacing. This encourages the model to relocate the source
event fromRtoEinmovingand to extend it overEinextend-
ing, while leaving the rest of the mixture largely unchanged.
3. Experimental Setup
3.1. Baselines and Implementation Details
We compared EMKR with several text-guided audio editing
models.SAO-Instruct[14] is an instruction-based diffusion ed-
itor for free-form audio editing; we set the classifier-free guid-
ance (CFG) [25] scale to 10 based on preliminary experiments.
AUDIT[12] is a latent diffusion editor driven by natural lan-
guage instructions that supportsadding,removing, andreplac-
ing, but does not supportmovingorextending.ZETA Tstart=50
andZETA Tstart=75 [26] are zero-shot DDPM inversion edi-
tors that use SAO [4] with 100 denoising steps; following the
SAO-Instruct setting, we controlled the editing strength via
Tstart∈{50,75}.AudioEditor[27] is a training-free diffusion
editor built on a pre-trained text-to-audio model, where edits are
guided by a target caption and a specified text region. For both
ZETA and AudioEditor, captions were generated from mixture
metadata using the same LLM-based pipeline as SAO-Instruct.
EMKR was trained for 60k steps with a batch size of 32 on a
single NVIDIA RTX 5090 GPU, taking about 40 hours. Follow-
ing the training setup of SAO-Instruct [14], we used AdamW
with a learning rate of5×10 −5 and initialized the model from
its pretrained checkpoint.
3.2. Dataset
We randomly sampled background scenes from the 10 s audio-
captioning corpus AudioCaps [28] and longer clips from the
BBC portion of WavCaps [29]. Foreground events were drawn
from ESC-50 [30], FSD50K [31], and shorter clips from the
BBC and Freesound portions of WavCaps. We evaluated all
models on 1,000 edited samples synthesized with the same on-
the-fly mixing pipeline used in training, using background, fore-
ground, and instruction combinations held out from the training
set. The test set was balanced across our tasks.
3.3. Evaluation Metrics
We evaluated editing performance using both objective and sub-
jective metrics. Objectively, we measured distributional similar-
ity (Fr´echet Audio Distance (FAD) [32], Fr´echet Distance (FD),
and Kullback-Leibler (KL) divergence), event-level correctness
(segment-based F1 (F1 seg) from PB-SED [33]), and signal fi-
delity (log spectral distance (LSD) and Scale-Invariant Signal-
to-Distortion Ratio (SI-SDR) [34]). Subjectively, we collected
mean opinion scores (MOS) on four dimensions: perceptual
quality (Quality), content relevance (Content), temporal accu-
racy (Temporal), and background faithfulness (Faithfulness).
Region-level objective evaluation.To analyze time-
localized editing behavior and temporal precision, we parti-
tioned each clip into task-specific regions: Non-Edit regions that
should remain unchanged, Source regions where foreground
events should disappear or be shortened, and Target regions
where foreground events should appear or be extended. In Non-
Edit regions, we computed LSD and SI-SDR between the edited
and original audio to measure the preservation of background
and non-target content. To directly assess time-localized event
correctness, we computed F1seg on 0.1 s segments, with the eval-
uation restricted to the Target interval ofadding,replacing,
moving, andextending. This region-level evaluation allows us
to test whether the model can control events at a fine (0.1 s)
temporal resolution within the specified time span. Forremov-
ing, the Target region contains only background, so F1seg is not
applicable. Therefore, we report only LSD and SI-SDR.
Clip-level objective evaluation.We computed FAD, FD,
and KL over entire clips to evaluate overall audio quality, fol-
lowing the evaluation protocol of AudioLDM [1]. Event-level
correctness was evaluated using F1 seg computed on 1.0 s and
0.1 s segments.

4. Results and Analysis
4.1. Region-level Objective Results
Table 1 summarizes region-level results for all five tasks, show-
ing how well each method edits the specified regions (Edit in
Table 1) while preserving the rest of the scene (Non-Edit in Ta-
ble 1). For edit performance inadding,removing, andreplacing,
EMKR consistently improved edit-region metrics. Inadding
andreplacing, its Target F1seg(0.1s)exceeded 80%, whereas all
other methods stayed far below. These high F1 seg(0.1s)scores
indicate that EMKR performs more precise edits with less tem-
poral error in the designated 100 ms Target intervals. EMKR
even slightly exceeded the ground truth in these F1 seg(0.1s)
scores. We attribute this to the fact that the weakly tagged source
datasets often leave silence gaps in the event labels, whereas
EMKR fills the specified Target intervals more completely. For
edit performance inmovingandextending, gains were most pro-
nounced, as these tasks are particularly preservation-critical be-
cause they must modify the target event while keeping the re-
maining content unchanged. EMKR attained superior region-
level F1seg(0.1s)in themoving- andextending-Target regions,
while all other models remained substantially lower, showing
that they often failed to place or extend the event over the in-
tended time span.
Across tasks, SAO-Instruct sometimes achieved better LSD
or SI-SDR in certain regions, but this mainly reflected that it of-
ten leaves the mixture largely unchanged rather than perform-
ing the intended edits. In contrast, EMKR actively modifies the
target events as instructed, which inevitably changes the wave-
form but yields much higher F1 seg(0.1s)and thus realizes the
intended temporal intervals, while still achieving the best or
second-best Non-Edit LSD and SI-SDR across tasks. This indi-
cates that EMKR can enforce the desired edits while preserving
the background scene more faithfully than SAO-Instruct.

4.2. Clip-level Objective Results
Table 2 summarizes clip-level objective scores averaged over
all tasks. EMKR achieved the lowest FAD, FD, and KL, indi-
cating that its edited outputs were closest to the reference audio
distribution. It also attained the highest F1 seg at both 1.0 s and
0.1 s resolutions, exceeding the best baseline by about 25% at
each resolution and achieving more accurate event localization
at both coarse (1.0 s) and fine (0.1 s) time scales. Together, these
clip-level metrics show that EMKR improves both overall per-
ceptual quality and event localization, rather than trading one
for the other.
4.3. Subjective Results
As shown in Table 3, EMKR achieved the highest MOS across
all four categories and approached the ground-truth audio, indi-
cating that its edits are preferred by human listeners. Although
SAO-Instruct sometimes obtained higher objective scores in
certain regions by leaving the audio largely unchanged, the
MOS results suggest that this strategy yields lower perceived
faithfulness and quality compared to EMKR. In particular,
EMKR received clearly higher scores in Temporal and Con-
tent, whereas competing editors remained close to the bottom
of the scale in these categories, showing that existing methods
can modify content but still face fundamental limitations in pre-
cise temporal editing.
4.4. Ablation Study
Table 4 shows the effectiveness of SEM for the preservation-
criticalmovingandextendingtasks. Without SEM, EMKR
lacked an explicit cue for the source instance, which could cause
collateral edits to the background or other occurrences. En-
abling SEM improved preservation in the Non-Edit and Source
regions for both tasks. It also improved target control. For
moving, SEM increased Target F1seg(0.1s)and lowered Target
LSD, while Target SI-SDR slightly decreased because reloca-
tion requires larger waveform changes. Forextending, SEM in-
creased Target F1 seg(0.1s), indicating better duration control.
Overall, SEM is essential to disambiguate the source instance
and reduce unintended edits.
5. Conclusion
We introduced EMKR, a SAO-based framework for text-guided
audio editing that supportsadding,removing,replacing,mov-
ing, andextendingwith instance-level, time-localized control in
polyphonic mixtures. By combining online temporal data gener-
ation, explicit timing conditioning, and SEM, EMKR edits the
specified event while largely preserving the rest of the audio
and outperforms prior editors, especially on temporally precise
movingandextendingoperations.
