Abstract
Programming education often assumes English proficiency and
text-based interaction, creating barriers for students in non-
English speaking countries like India. We presentCodeVaani,
a multilingual voice-enabled code assistant built into IIT Bom-
bay’s Learning Management System, helping learners explore
programming concepts in their native languages. The system in-
tegrates Indic ASR, a code-aware transcription refinement, and
a code model to generate responses in both text and audio. In
a study with 28 beginner programmers, over 89% rated the ex-
perience as fair or above. CodeVaani offers on-demand, scal-
able, multilingual support, lowering the entry barrier for stu-
dents with limited English proficiency and demonstrating how
voice-based AI can make programming education more inclu-
sive. Supplementary artefacts and demo video are available12.
Index Terms: speech recognition, human-computer interac-
tion, computational paralinguistics
1. Introduction
AI-based chat assistants have emerged as useful tools for in-
teractive code understanding, but most assume English profi-
ciency and text-based interaction. This excludes learners in
non-English speaking countries like India, where many students
transition from regional language schooling to English-medium
CS curricula, making limited English fluency and typing skills
an additional barrier.
V oice-based interfaces offer a promising alternative [1]. We
did a survey of 53 Indian programmers, found that only 58.5%
considered themselves English-proficient, and 54.7% preferred
voice over text for code-related queries. However, building such
systems is non-trivial: spoken programming queries are code-
mixed, syntactically irregular, and rich in out-of-vocabulary
terms. Standard ASR systems [2] frequently misinterpret such
inputs, degrading downstream LLM performance [3].
We presentCodeVaani, a multilingual speech-driven as-
sistant for code understanding built into IIT Bombay’s Learn-
ing Management System. It transcribes spoken native-language
queries via ASR, refines them through code-aware LLM pro-
cessing, and generates responses delivered in both text and au-
dio for accessible, on-demand learning.
2. CodeVaani: Voice-Driven Code Learning

comprises three stages: speech recognition, code-aware tran-

2.1. Speech Recognition
ASR systems convert speech audio into text, recovering nat-
ural language and code-specific tokens. Initial experiments
with Whisper revealed limitations with mixed-language inputs,
particularly queries having native language words with En-
glish code terms. We therefore useWhisperfor English and
Indic-Conformerfor Indic languages, which are trained on
Indian speech data and better preserve mixed-language seman-
tics. These models do not fully resolve the problem, hence we
address these residual ASR errors in the refinement stage.
2.2. Code-Aware Transcription Refinement
Recognition errors persist for variable names, symbolic op-
erators, and programming keywords in multilingual queries.
We introduce acode-aware transcription refinementstage us-
ing instruction-tunedGemma-27Bwith Direct Preference Op-
timization finetuning to post-process ASR outputs. The prompt
corrects misrecognized, phonetically distorted technical words
(e.g., “ask key”→“ASCII”), and symbolic constructs (e.g.,
underscore→ ). This strategy allows the model to recon-
struct original code-like phrases even when mispronounced or
substituted with similar-sounding non-technical words.
2.3. Query Response Generation
The refined transcription is passed toCodestral-22B, which
generates contextually relevant responses across code expla-
nation, question answering, and debugging tasks. The model
handles queries in multiple Indian languages and produces re-
sponses in the same language. By integrating the transcription
refinement and code generation stages, CodeVaani ensures that
even queries with phonetic errors or code-mixed language are
correctly interpreted, resulting in more reliable responses.
2.4. Implementation Details
CodeVaani (Figure 1) uses a ReactJS frontend, Django back-
end, PostgreSQL database, Redis task queue, and Celery work-
ers. AI models run on a dedicated server with 2 H100 GPUs:
one for ASR (Indic-Conformer or Whisper) and transcription
refinement (Gemma-27B), and another for response generation
(Codestral-22B). Students record queries via the browser; the
backend logs the request, queues an async Celery task, and re-
turns a TaskID for polling. The GPU server transcribes the au-
dio, refines the transcription, and generates the response, which
is delivered back to the student alongside the corrected query.

3. Evaluation
We conducted a structured lab evaluation with 28 beginner pro-
grammers spanning all major Indian languages (Hindi, Marathi,
Gujarati, Tamil, Telugu, Bengali, Malayalam, Kannada, and
Odia), using journals and a follow-up Google Forms survey.
3.1. Usability Survey
Over 89% of participants rated their experience as fair or above
(Excellent: 10.7%, Good: 32.1%, Satisfactory: 28.6%, Fair:
10.7%, Needs Improvement: 17.9%). When asked whether they
would use CodeVaani in their programming course if concerns
were resolved, 25 out of 26 respondents answered “Yes, defi-
nitely” or “Yes, probably,” indicating strong adoption intent.
3.2. Evaluation on Human-Speech Queries
To assess robustness on real speech, five participants (one per
language: English, Hindi, Marathi, Gujarati, Bengali) each
recorded 100 code-related spoken queries (500 total). We com-
puted Word Error Rate (WER), Phoneme Error Rate (PER), and
Weighted Feature Edit Distance (WFED) considering Code-
Vaani and compared Indian ASR model (designed for code-
mixed speech):Saaras V3(SarvamAI), supporting 22 Indian
languages with enhanced code-mixed and noisy speech recog-
nition. As shown in Table 1, CodeVaani significantly outper-
forms across all languages and metrics, with particularly large
WER reductions, demonstrating superior handling of code-
mixed multilingual speech.

4. Conclusion & Future Work
We introduced CodeVaani, a speech-driven multilingual code
assistant that achieved over 89% fair or above user ratings, high-
lighting the promise of voice-first interfaces in making pro-
gramming education more accessible beyond English-centric
settings. In future, we plan to extend CodeVaani by enabling
multi-turn conversational interactions, improving robustness
with large-scale code-mixed speech data and unifying ASR cor-
rection with response generation for low-latency deployment.
