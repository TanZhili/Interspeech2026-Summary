Abstract
The ExELang Legacy Support Interface (ELSI) is an open-
source interface designed to support researchers studying lan-
guage acquisition in diverse communities around the world.
ELSI enables users, regardless of technical expertise, to stan-
dardize child-centered datasets, apply machine learning mod-
els trained on child-centered audio (e.g., speaker diarization,
phoneme counts), and extract key metrics such as child vo-
calization count, adult vocalization count, and conversational
turns. During the Show and Tell, we will demonstrate how to
use the interface by walking through dataset standardization,
model execution, and metric extraction. We expect ELSI to be
particularly valuable for researchers who maintain large child-
centered audio datasets and wish to leverage open-source ma-
chine learning tools without requiring advanced programming
skills.

1. Introduction
Developmental psychologists and linguists rely heavily on long-
form recordings (LFRs) of child-centered audio, typically col-
lected via lightweight microphones that children wear through-
out the day. These naturalistic recordings capture the full rich-
ness of a child’s language environment, including caregiver
speech, peer interaction, and their own vocalizations, and have
become a critical component of early language acquisition re-
search [1]. The scale and diversity that make LFRs so valu-
able also make them technically demanding for individual re-
searchers to process and analyze, particularly those without ad-
vanced programming expertise.
ELSI addresses three interrelated problems in LFR re-
search. First,corpus heterogeneity: datasets lack shared stan-
dards for directory structure, file naming, metadata, and anno-
tation format, making cross-corpus analysis tedious and error-
prone. Second,tool accessibility: existing models for child-
centered audio analysis require command-line or Python exper-
tise that many developmental researchers lack, and the domi-
nant commercial tool (LENA; [2]) is closed-source. Third,met-
ric reliability: commonly reported measures (e.g. vocalization
counts, turn counts, adult word counts) are sensitive to underly-
ing model quality, yet researchers have few means to evaluate
or compare model outputs systematically.
In response, ELSI (Figure 1) provides: (1) automated cor-
pus standardization to a common format; (2) one-click access
to validated open-source models; and (3) systematic tools for

The challenges ELSI addresses are directly relevant to the

just well-funded labs with engineering support, to participate

2. Related Work
2.1. The ChildProject Framework
ChildProject [3] is a Python package that addresses corpus het-
erogeneity by enforcing a consistent directory structure and
metadata schema across LFR corpora, with built-in validation
tools to verify conformity before analysis. ELSI utilizes the
ChildProject pipeline under the hood, eliminating the require-
ment that users need any command-line interaction.
2.2. Machine Learning Models
ELSI integrates open-source models for child-centered audio
analysis. The V oice Type Classifier (VTC) [4] segments au-
dio by speaker type (e.g., key child, other child, adult female,
adult male), producing time-stamped labels that drive down-
stream metric extraction. The Automatic LInguistic Unit Count
Estimator (ALICE) [5] estimates adult-uttered phoneme counts
by combining voice activity detection with an acoustic model,
providing a transcription-free proxy for adult linguistic input
suitable for large-scale corpora.
2.3. Metrics
From these model outputs, ELSI extracts child vocaliza-
tion count, other child vocalization counts, female and male
adult vocalization counts, and conversational turns, as well as
phoneme, syllable, and word counts.

3.2. Demonstration Walkthrough
During the Show and Tell session, we will demonstrate how to
use ELSI (Figure 1) with a sample corpus, emphasizing the ex-
perience of a researcher with no programming background. The
walkthrough will cover how to deposit data safely into scientific
archives for data protection, how to use ELSI to run open-source
models, how to get metrics in an exportable CSV , and how re-
searchers can optionally join a larger consortium to contribute
their data to cross-corpus science.
4. Future Directions
ELSI has been piloted through an European Research Council
grant and with collaborator coprora. Currently, we are work-
ing towards developing a sustainable model. The code is open-
source for others to be able to host. We plan to expand the set of
integrated models as new open-source tools for child-centered
audio are released. We aim to grow the network of research
teams contributing to and benefiting from the platform, with the
goal of establishing ELSI as shared infrastructure for the LFR
research community.
