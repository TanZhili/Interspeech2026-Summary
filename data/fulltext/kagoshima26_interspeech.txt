POP-SED: Prototype Orthogonal Projection for Robust
Few-shot Sound Event Detection
Takehiko Kagoshima1
1 Corporate Laboratory, Toshiba Corporation, Japan
takehiko.kagoshima.r78@mail.toshiba
Abstract
Few-shot sound event detection (SED) must operate with
limited examples that often contain overlapping background
sounds, making robust detection challenging. We present proto-
type orthogonal projection for SED (POP-SED), a fine-tuning-
free method that suppresses background influences by project-
ing the target-event prototype onto a subspace orthogonal to
background vectors. Background vectors are obtained by fit-
ting a von Mises–Fisher mixture model to features from back-
ground and query intervals, and then selecting a subset of mean
vectors that maximizes a robustness-aware support-set criterion.
On the DCASE2024 Task 5 validation set, POP-SED achieved
an F-score of 62.35% without any fine-tuning, approaching the
accuracy of top-performing systems that require both domain-
level and support-set fine-tuning.
Index Terms: Sound Event Detection (SED), Few-shot learn-
ing, Prototype orthogonal projection, DCASE2024 Task 5.
1. Introduction
Few-shot learning (FSL) aims to learn new concepts from only
a few labeled samples by leveraging prior knowledge acquired
from other data-rich tasks. It is typically formulated as an N-
way K-shot problem, where each task consists of a support set
containing K labeled samples for each of N classes and a query
set of unlabeled samples to be classified.
Few-shot sound event detection (SED) is a specific in-
stance of this framework, aiming to detect target acoustic events
from limited support set samples. It is particularly impor-
tant for applications where collecting labeled audio data is
impractical[1, 2]. Despite its potential, few-shot SED faces
key challenges, notably learning robust and discriminative rep-
resentations from scarce suport set samples. To address this,
recent studies leverage pre-trained acoustic foundation models
as transferable feature extractors. These include self-supervised
models such as BEATs[3, 4] and OpenBEATs[5], multimodal
contrastive models such as CLAP[6, 7, 8], and transfer learn-
ing approaches such as AST[9, 10]. Additionally, fine-tuning
these models on domain-specific data has been shown to im-
prove performance. For example, in bioacoustic event detec-
tion, A VES[11] and GPM-BT[12] adapt pre-trained representa-
tions to specialized environments.
Prototype-based methods are widely used in few-shot
learning[13, 14, 15, 16] here class representations are formed
from support set samples and used for classification of query
set samples. However, in few-shot SED, the presence of back-
ground sounds poses a critical challenge, as target events in both
support and query data are often overlapped with background
sound. In practical settings, clean event examples are diffi-
cult to obtain, and support set samples frequently contain back-
ground interference. To address this issue, recent approaches
adapt detection models to background conditions by fine-tuning
with both support and query data[17, 18, 19]. While effective,
such approaches introduce significant computational overhead
and limit the flexibility of adapting to new events. Therefore,
achieving background-robust detection without fine-tuning re-
mains an important challenge for few-shot SED.
In this paper, we propose prototype orthogonal projection
for SED (POP-SED) that enables background robust few-shot
SED without fine-tuning the audio encoder. POP-SED sup-
presses background influences by projecting the target event
prototype—computed from the support set—onto a subspace
orthogonal to the estimated background vectors. The back-
ground vectors are derived from the distribution of background
features in the support set and features in the query set, allow-
ing adaptation without additional training. By eliminating the
need for fine-tuning, POP-SED offers a lightweight and flexible
solution for on-site customization of few-shot SED. Experimen-
tal results on the DCASE2024 Task 5 validation set demonstrate
that POP-SED, when combined with a general-purpose acoustic
encoder such as BEATs, achieves detection performance com-
parable to fine-tuned models while maintaining the efficiency
and adaptability expected in few-shot learning.
The main contributions of this paper are as follows:
1. Orthogonal projection-based adaptation using POP-SED: A
fine-tuning-free adaptation method that projects the target-
event prototype onto a subspace orthogonal to background
vectors, thereby suppressing background sounds.
2. Evaluation on DCASE2024 Task 5: POP-SED with BEATs
achieves performance comparable to fine-tuned models,
while retaining the efficiency and flexibility of few-shot
learning.

3. Proposed method (POP-SED)
3.1. Overview of prototype projection
The query-time detection pipeline of POP-SED follows the
baseline few-shot SED system described in Section 2: an acous-
tic foundation model acts as a fixed audio encoder, a prototype
of the target event is formed from the support set, and cosine-
similarity thresholding is used to decide event frames. When us-
ing pre-trained models, a mismatch between the input and train-
ing data sampling rates often requires preprocessing. In this
work, we apply waveform stretching instead of conventional re-
sampling to address this issue; however, this step is independent
of POP-SED and not considered part of the proposed method.
The key difference is that POP-SED projects the target-event
prototype onto a subspace orthogonal to estimated background
vectors before computing similarity, thereby suppressing back-
ground contributions without model fine-tuning.

probabilistic model of feature distributions using (i) NEG fea-
tures from the support set and (ii) features extracted from the
query set. Because detection is based on cosine similarity, the
feature-vector norm carries no semantic weight; therefore, we
model feature vectors on the unit hypersphere using the von
Mises–Fisher (vMF)[20] family. Specifically, we represent the
feature distribution with anM-component vMF mixture model
(vMFMM):

4. Experiments
4.1. Evaluation dataset
For evaluation, we use the validation set included in the devel-
opment set of DCASE2024 Task 5 (Few-shot Bioacoustic Event
Detection). Since our approach does not involve fine-tuning the
audio encoder, the training set is not used. The validation set
consists of six subsets: HB, PB, ME, RD, PB24, and PW, each
containing multiple audio recordings with corresponding label
files specifying the onset and offset times of target events. For
each recording, the audio segment from the beginning to the
end of the fifth labeled event is used as the support set, and the
remaining audio is treated as the query set, forming a one-way
five-shot sound event detection task. The evaluation metric is
the event-based F-measure, computed using the official evalua-
tion tool provided by DCASE2024 Task 5.
4.2. Experimental setup
We evaluated the proposed method using two pre-trained
acoustic foundation models as audio encoders: BEATs
(iter3+AS2M)[21] and CLAP (2023 version)[22]. BEATs is
a Vision Transformer (ViT)-based model[23] with 12 Trans-
former layers, approximately 90M parameters, and a 768-
dimensional embedding. CLAP employs a CNN14[24] ar-
chitecture with about 80M parameters and produces 1024-
dimensional embeddings. No fine-tuning was applied to ei-
ther encoder, ensuring that the experiments reflect the few-shot
adaptation capability of the proposed approach. The analysis

method, we compared three configurations:
1. Baseline: Few-shot SED without prototype projection.
2. Full background model: Projection using all mean vectors
from the vMFMM without subset selection.
3. Proposed POP-SED: Projection using the optimally selected
subset of background vectors as described in Section 3.3.
4.3. Experimental results
Table 1 compares the detection performance of the proposed
POP-SED method with the top three systems[17, 18, 19] from
DCASE2024 Task 5 (validation set). The competing systems
had their audio encoders fine-tuned using the Task 5 training
set and were further adapted to the support set, whereas POP-
SED uses pre-trained general-purpose models without any fine-
tuning. The results in Table 1 indicate that POP-SED achieves
an F-score of 62.35% with BEATs and 53.21% with CLAP, de-
spite using no fine-tuning, whereas the competing systems rely
on domain-specific and support-set fine-tuning. This demon-
strates that POP-SED enables fine-tuning-free customization,
making few-shot SED practical for real-world deployments.
Next, Table 2 shows the effect of POP compared with the
baseline and full background model approach across all sub-
sets. As seen in the table, the baseline without projection per-
forms poorly on subsets with strong background interference
(e.g., PB, PB24), while POP-SED significantly improves per-
formance, confirming the effectiveness of POP. The full back-
ground model approach improves over the baseline but un-
derperforms compared with POP-SED, highlighting the impor-
tance of subset selection for background vectors.
Table 3 presents the results of an ablation study evaluating
the impact of background vector selection criterion, preprocess-
ing method, and probabilistic model type:
• Using IoU(θ) + IoU(θ +δ) improves robustness over IoU(θ)
alone (+5.1 points), highlighting the importance of account-
ing for threshold variability.
• Replacing vMFMM with a Gaussian mixture model reduces
performance (−4.3 points), suggesting that modeling direc-
tional distributions on the hypersphere is more suitable for
cosine-based similarity.
• Waveform stretching outperforms resampling (+14.8 points),
validating the importance of preserving high-frequency com-
ponents.
These findings confirm that projection, subset selection, and
vMF modeling contribute to robust few-shot detection, while
waveform stretching provides additional gains.
Finally, we analyze the computational cost of POP-SED. In
our experiments, its inference time was comparable to the base-
line, indicating that the overhead of prototype projection and
background vector selection is negligible relative to the audio
encoder. WithM = 4 vMFMM components, this cost remains
small; however, since the complexity of background vector se-
lection scales as 2M , it may increase rapidly for largerM.
5. Conclusion
This paper introduced POP-SED, a fine-tuning-free framework
for few-shot sound event detection that achieves robustness to
overlapping background sounds. The key idea is to project
the target-event prototype onto a subspace orthogonal to back-
ground vectors estimated from vMFMMs fitted to NEG and
query features. Experiments on the DCASE2024 Task 5 demon-
strate that POP-SED achieves an F-score of 62.35%, compara-
ble to top-performing systems that require domain and support-
set fine-tuning. Future work includes developing scalable back-
ground vector selection methods for largerM.
