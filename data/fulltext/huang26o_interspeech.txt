Neural Directional Coding: Joint Spatial Coding and Filtering
with Configurable Directivity Patterns

Abstract
Recent neural directional filtering methods enable the syn-
thesis of virtual microphone signals with configurable high-
order directivity patterns using only a few omnidirectional mi-
crophones. In communication scenarios, spatial signal process-
ing at the receiver is often desired, yet transmitting all micro-
phone array data requires high bit rates. We propose neural di-
rectional coding (NDC), a neural network-based approach for
joint spatial coding and filtering that compresses only spatial
information. At the receiver, a virtual directional microphone
signal with a configured directivity pattern can be reconstructed
from the compressed spatial information and a single-channel
reference signal. Experiments with a 4-channel, 16 kHz micro-
phone array show that spatial information can be compressed to
0.25 kbps using a 1.4 M parameter model, matching or surpass-
ing a 7.5 kbps baseline with 90.8 M parameters.
Index Terms: Spatial filtering, Directional audio coding, Vir-
tual directional microphone, Microphone array
1. Introduction
Neural audio coding achieves high-fidelity reconstruction for
single-channel audio at low bit rates, e.g., SoundStream [1], En-
codec [2], and HiFi-codec [3]. Building on the HiFi-codec deep
neural network (DNN) architecture, SpatialCodec [4] extends
neural coding to microphone array signals by compressing all
signals into side information transmitted alongside a reference
channel. At the decoder, this side information is decoded into
complex ratio filters to reconstruct all microphone array signals.
Instead of reconstructing original array signals, directional
audio coding (DirAC) [5] is an efficient parametric approach
for spatial audio coding. The approach was initially proposed
for first-order Ambisonics (FOA) [5–7], but was later extended
to high-order Ambisonics (HOA) [8] and arbitrary microphone
array geometries [9]. This parametric approach has also been
adopted to perform spatial filtering [10, 11]. More recently,
DNN-based methods have been proposed to code FOA [12, 13]
at relatively low bit rates, e.g., 0.9 kbps in [13].
Recently, neural directional filtering (NDF) [14] was pro-
posed to perform spatial filtering with high-order directivity pat-
terns using only a few omnidirectional microphones, achieving
frequency-invariant patterns even above the spatial aliasing fre-
quency [15]. NDF was later extended to neural directional filter-
ing with user-defined directivity patterns (UNDF) [16], which
enables spatial filtering with configurable high-order directiv-
ity patterns during inference, providing a flexible solution to
synthesize arbitrary virtual directional microphone signals for

This work proposes neural directional coding (NDC), a
neural network-based approach for joint spatial coding and spa-
tial filtering. The encoder compresses only the spatial informa-
tion rather than all array signals. After transmission, instead of
reconstructing all signals, a non-linear spatial filter with a con-
figured directivity pattern is estimated and applied to a single-
channel reference signal to produce the final output. Here, the
spatial filter is realized as a single complex mask. This out-
put can approximate any virtual directional microphone with
configurable directivity patterns. The reference signal can be
encoded using any existing single-channel audio codec. Ex-
perimental results demonstrate that spatial information from
a 4-channel, 16 kHz microphone array can be compressed to
0.25 kbps using a model with 1.4 M parameters, surpassing
the performance of a 7.5 kbps baseline (90.8 M parameters)
that represents a straightforward cascade of SpatialCodec and
UNDF.

3. Proposed Method
3.1. DNN architecture and training loss
Our method transmits a reference microphone signal using a
standard single-channel codec, while compressing the array’s
spatial information as auxiliary data. This work focuses on
spatial information coding rather than single-channel coding.
For coding of the reference signal, we use the standardized En-
hanced V oice Services (EVS) codec [19] as an example.

in Table 1. Both rates were obtained by quantizing the spatial

the two corresponding frames at the spatial decoder (a temporal

LSTM and FiLM settings for the spatial filter estimation mod-

5. Results and Discussions
BaselinesThe proposed NDC is trained with two primary mod-
ules—spatial information coding and spatial filtering—jointly
optimized. To assess the value of this joint training, we establish
a baseline using a cascade of SpatialCodec [4] and UNDF [16],
where the two components are trained independently. Follow-
ing [4], the original SpatialCodec reconstructs all microphone
array signals, which are then processed by UNDF for spatial fil-
tering. SpatialCodec is trained using the first-stage NDC train-
ing data, while UNDF is trained on the second-stage data, en-
suring both models use the same datasets as the proposed NDC.
For fair comparison, the independent SpatialCodec adopts the
same network architecture as the coding part of NDC at each
bitrate. In Table 2, we denote the SpatialCodec at 0.25 kbps as
SpatialCodec(S), at 0.5 kbps as SpatialCodec(M), and the orig-
inal version at 7.5 kbps as Original SpatialCodec. Additionally,
we include a parametric filter baseline [10] that processes the
original signals directly, since parametric filtering remains an
effective method for spatial filtering with configurable direc-
tivity patterns. The parametric filter is computed using oracle
DOA estimates, providing an upper bound on its performance.
Overall resultsTable 2 presents the evaluation results for all
proposed and baseline models on four test sets, each with a dis-
tinct directivity pattern configuration. The2 nd-order Cardioid
pattern (µ= 0.5) is included in the training set. The5.5 th-order
Cardioid pattern has a fractional order, which is practical for
fixed beamforming [29, 30], but was not observed during train-
ing. The12 th-order Cardioid pattern exceeds the highest order
used in training. The14 th-order pattern withµ= 0.25intro-
duces both a higher order and an unseenµvalue. Overall, our
proposed NDCs consistently outperform the baseline in both
SDR and PESQ at their respective bit rates (0.25 and 0.5 kbps),
with both NDC variants achieving comparable performance.
Notably, the NDC at both 0.25 kbps and 0.5 kbps mostly
outperforms the 7.5 kbps baseline and the performance of para-
metric spatial filtering. In terms of model size, the 7.5 kbps
baseline consists of 89.9 M (SpatialCodec) and 948 K (UNDF)
parameters, totaling 90.8 M. In contrast, the NDC requires only
1.4 M parameters. These findings demonstrate that spatial infor-
mation in microphone-array signals can be accurately encoded
for spatial filtering at ultra-low bit rates with lightweight mod-
els.

6. Conclusions
We proposed Neural Directional Coding (NDC), a neural
network-based framework for joint spatial coding and spatial
filtering. The encoder compresses spatial information at an
ultra-low bitrate of 0.25 kbps, while the single-channel refer-
ence signal is transmitted using EVS coding. After transmis-
sion, a spatial filter with a configurable directivity pattern is
estimated and applied to the reference channel to generate the
final output. This spatial filter enables flexible approximation
of virtual directional microphones with configurable directivity
patterns. Experimental results show that the spatial cues from
a 4-channel, 16 kHz microphone array can be compressed to
0.25 kbps using an NDC model with only 1.4 M parameters,
achieving performance comparable to a 7.5 kbps baseline us-
ing 90.8 M parameters. Furthermore, reverberant si
