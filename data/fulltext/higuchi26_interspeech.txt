Abstract
End-to-end spoken dialogue state tracking (DST) infers be-
lief states directly from speech, avoiding cascading errors in
ASR–DST pipelines. This paper proposes an incremental DST
method using a multimodal large language model (Qwen2.5-
Omni-7B) that generates transcripts and symbolic state updates
from raw audio. Unlike conventional approaches that regen-
erate the full state each turn, our method predicts only sym-
bolic edit operations relative to the previous state, reducing
output length and the risk of corrupting unchanged slots. We
apply a two-stage training recipe: supervised fine-tuning fol-
lowed by Group Relative Policy Optimization (GRPO), which
directly optimizes generation-level rewards for transcript ac-
curacy, DST correctness, and format validity. Experiments
on SpokenWOZ demonstrate that incremental updates substan-
tially outperform full-state prediction, and GRPO further im-
proves accuracy, achieving the best reported results on this
benchmark.
Index Terms: spoken dialogue systems, dialogue state track-
ing, multimodal LLM, reinforcement learning, GRPO
1. Introduction
Task-oriented dialogue systems must maintain a structured rep-
resentation of the user’s goals, constraints, and requests as a
dialogue progresses. Dialogue state tracking (DST) estimates
this belief state from the interaction history. When users speak,
a common approach is a cascade of automatic speech recog-
nition (ASR) followed by text-based DST [1]. The DSTC-11
challenge [2] highlighted the gap between written and spoken
dialogue by constructing spoken variants of MultiWOZ 2.1 [3],
and subsequent approaches attempted to mitigate ASR errors
through explicit correction modules [4]. Nevertheless, such cas-
cades inherently suffer from error propagation: ASR mistakes
can severely corrupt downstream state updates.
An emerging alternative is to bypass ASR entirely by using
multimodal large language models (MLLMs) that process au-
dio directly [5, 6, 7, 8, 9]. Qwen2.5-Omni [10] represents the
current state of the art among publicly available models in this
line, achieving end-to-end multimodal perception with a unified
encoder–decoder architecture. However, simply replacing the
ASR–DST cascade with an MLLM does not resolve a second,
independent challenge: how to efficiently and robustly maintain
the belief state across multiple turns.
In text-based DST, generative approaches such as
TRADE [11] and SimpleTOD [12] typically regenerate the full
belief state at each turn. Incremental approaches, which con-
dition on the previous belief state and predict only the changed
slots, have also been explored—for example, SOM-DST [13]
selectively overwrites a belief state memory, and MinTL [14]
introduces Levenshtein belief spans. Although these incremen-
tal methods were once in the minority, they have attracted re-
newed interest in the LLM era: regenerating the full state at
every turn inflates output length and risks hallucinating values
for unchanged slots, whereas incremental updates let the model
focus on what actually changed [15, 16]. To the best of our
knowledge, existing end-to-end spoken DST approaches have
yet to benefit from this shift, still employing full-state predic-
tion [17], which becomes increasingly inefficient and prone to
spurious slot errors as dialogues grow longer.
To address the limitations of full-state prediction in end-
to-end spoken DST, this paper proposes a framework using
Qwen2.5-Omni-7B [10] with an incremental state update strat-
egy. Instead of predicting the full state (e.g., {"restauran
t":{"food":"indian", "area":"north", "tim
e":"18:00",...}} ), our model outputs symbolic edit op-
erations (e.g., update(restaurant.food=indian) ),
conditioning on the previous belief state. Compared to full-
state prediction, this incremental approach reduces the output
length and allows the model to focus on the specific changes in
the current turn, thereby mitigating the risk of corrupting un-
changed slots. On the other hand, because incremental updates
condition on previous predictions at inference time, a single er-
roneous edit can propagate to all subsequent turns, making per-
turn accuracy even more critical. We therefore apply Group
Relative Policy Optimization (GRPO) [18], which has recently
been shown to improve ASR robustness [19], to directly opti-
mize generation-level rewards—transcript quality, update cor-
rectness, and format validity—that the token-level SFT objec-
tive alone cannot capture. The main contributions of this paper
are as follows:
• The first application of incremental belief state updates to
end-to-end spoken DST, extending the paradigm to direct au-
dio input. The model predicts a constrained set of symbolic
slot-level edit operations conditioned on the previous belief
state, yielding more compact outputs than prior full-state ap-
proaches.
• A multi-component GRPO reward jointly optimizing tran-
scription quality and edit-operation correctness, motivated
by the error propagation sensitivity inherent to incremental
inference—where a single erroneous edit cascades across all
subsequent turns.
• Empirical evaluation on SpokenWOZ showing that our in-
cremental formulation outperforms the full-state baseline by
3.16 JGA points, with GRPO further improving both JGA
and WER.
• Public release of code and trained model to support repro-
ducibility and future research.1

2. Methods
We propose an end-to-end spoken dialogue state tracking
framework that directly maps audio input and dialogue history
to belief state updates. Figure 1 illustrates the data flow of the
proposed incremental method: the system takes the text dia-
logue history, the previous belief state, and the current user
audio as input, and a multimodal large language model gener-
ates a transcript along with symbolic edit operations to update
the belief state. Our approach adopts an incremental strategy:
rather than regenerating the full belief state at every turn—as in
conventional generative DST methods [12, 11]—the model pre-
dicts symbolic edit operations (e.g., updates or deletions) rela-
tive to the previous state, inspired by the efficiency of differ-
ential state tracking proposed for text-based systems [14]. To
ensure high-quality transcription and robust state tracking, we
employ a two-stage training pipeline consisting of Supervised
Fine-Tuning (SFT) for initial alignment and format learning,
followed by Group Relative Policy Optimization (GRPO) [18]
to directly optimize generation-level metrics that SFT’s token-
level loss does not capture.
2.1. Task Formulation
LetHt denote the dialogue history up to turnt−1,at the current
audio input, andBt the belief state at turnt. The model outputs
(i) a transcript for the current turn and (ii) the updated belief
stateBt.
2.2. Incremental DST
We propose an incremental DST formulation where the model
conditions on the previous belief stateBt−1 and predicts a set of
edit operations ∆t (see Figure 1). Specifically, the input is con-
structed by concatenating the text-based dialogue history Ht,
the previous belief state Bt−1, and the current audio input at
using explicit section headers. The prompt follows a template:
[DialogueHistory] followed by the turn-by-turn con-
text, [PreviousState] followed by the JSON string of
Bt−1, and finally [NewAudio] followed by the current au-
dio input at. The operation vocabulary is constrained to three
types: set(domain.slot=value) (initialize a new slot),
update(domain.slot=value) (modify an existing slot),
and delete(domain.slot) (remove a slot). The new
belief state is obtained by applying ∆t toBt−1.
This formulation yields compact outputs and focuses the
model on changes. However, at inference time a single incorrect
edit can corrupt all later states in predicted-mode evaluation,
so output quality is critical. To improve the overall quality of
generated transcripts and edit operations, we complement SFT
with reinforcement learning via GRPO.
2.3. Model and Training
2.3.1. Multimodal LLM and adaptation
We employ a multimodal LLM capable of processing both au-
dio and text within a single decoder. This architecture elimi-
nates the need for external connectors or separate ASR modules,
allowing direct utilization of paralinguistic cues for DST. To re-
duce memory and computational costs, we adapt the model with
parameter-efficient fine-tuning (PEFT) via QLoRA [20], apply-
ing LoRA adapters only to the LLM component while keeping
the audio encoder and modality aligner frozen.

2.3.2. Stage 1: Supervised fine-tuning (SFT)
We first fine-tune the model with teacher forcing on paired au-
dio and labeled DST outputs. For incremental DST, the target
output follows a strict format: <transcript>...</tra
nscript> and <answer>...</answer> . The SFT stage
aims to establish the basic alignment between audio and text,
ensuring the model learns valid output syntax and acquires the
ability to transcribe and generate correct state updates. Impor-
tantly, the model never outputs the full belief state directly; it
produces only the transcript and the set of symbolic edit opera-
tions, leaving state reconstruction to a deterministic application
of ∆t toBt−1.
2.3.3. Stage 2: Reinforcement learning with GRPO
SFT alone optimizes a token-level cross-entropy loss, which
does not directly correspond to the generation-level metrics
used in evaluation (e.g., word error rate, edit-operation F1). We
therefore apply Group Relative Policy Optimization (GRPO)
starting from an SFT checkpoint to explicitly optimize these
sequence-level objectives. For each prompt (audio + context),
we sample K candidate generations and compute a scalar re-
ward for each. Policy updates are based on relative performance
within the group, with a KL penalty to limit drift from the ref-
erence policy.
2.4. Reward Design
The reward is a weighted sum of interpretable components, nor-
malized to lie in [0, 1]. We use the following formulation:
r =αr wer +βr diff-f1 +γr exact +δr format, (1)
whererwer = max(0, 1−WER) is based on the transcript word
error rate,rdiff-f1 is the F1 score between predicted and reference
edit-operation sets,rexact∈{ 0, 1} is a binary bonus that equals
1 if the predicted edit set exactly matches the reference and 0
otherwise, and rformat checks whether required tags and opera-
tion syntax are valid. The weights α,β,γ,δ are hyperparame-
ters satisfyingα+β +γ +δ = 1; their specific values are given
in Section 3.2.
The format score decomposes into: presence of <transc
ript> (+0.3), presence of <answer> (+0.3), and validity of
the operation string (+0.4; an empty set is treated as valid).
3. Experimental Setup
3.1. Datasets and Metrics
We evaluate our method on the SpokenWOZ dataset [1], which
comprises 5,700 human-to-human spoken task-oriented dia-
logues spanning 8 domains with over 203k turns. From the orig-
inal training split of 4,700 dialogues, we reserve 100 dialogues
as a validation set and use the remaining 4,600 for training. The
test set consists of 1,000 dialogues.
For evaluation, we employ three key metrics: (1) Word Er-
ror Rate (WER) measures the transcription accuracy. (2) Joint
Goal Accuracy (JGA) is the primary DST metric, defined as
the percentage of turns where the predicted belief state exactly
matches the ground truth state for all slots. (3) Slot Error Rate
(SER) is calculated as the sum of slot substitutions, insertions,
and deletions divided by the total number of slots in the refer-
ence labels [21].
We evaluate both an oracle mode and a predicted mode.

3.2. Model Configuration

for all experiments. We adapt the model with QLoRA [20],
using rank 64 and alpha 128, training in 4-bit NF4 quantiza-
tion with double quantization. We compute in bfloat16 and
use DeepSpeed ZeRO-2, Flash Attention 2, and gradient check-
pointing.
3.3. Baselines
We compare our proposed method against the following base-
lines:
SPACE+WavLMalign [1] is a cascade baseline proposed in the
SpokenWOZ paper. It employs an ASR-based pipeline aug-
mented with speech embeddings from WavLM for alignment,
representing the conventional approach to spoken DST.
Gemma-2-9B-Instruct [17] is an end-to-end approach align-
ing a speech encoder with an LLM and generating the full be-
lief state at each turn. Sedl ´aˇcek et al. also report results with
ontology-based fuzzy matching (+FUZZY) as post-processing.
Qwen2.5-Omni-7B (Full-State) follows the same full-state
generation approach as Sedl´aˇcek et al. [17], but uses Qwen2.5-
Omni-7B as the base model. The model predicts the entire be-
lief stateBt at each turn as a JSON object (e.g., {"domain":
{"slot":"value",...},...} ). This baseline uses the
same Qwen2.5-Omni-7B base model and is trained with SFT
only, allowing a direct comparison of the DST formulation (full-
state vs. incremental) under the same model architecture.

4.4. Ablation Study
To investigate the contribution of the WER reward component
in GRPO, we train a variant with the WER reward term re-
moved. As shown in Table 4, removing this component de-
grades both transcription quality (WER increases from 21.61%
to 23.37%) and DST accuracy (JGA decreases from 49.20% to
48.34%). These results indicate that GRPO’s gains in JGA are
driven primarily by improved transcription: cleaner transcripts
reduce the noisiness of the dialogue history fed into subsequent
turns, thereby mitigating the error propagation identified in Sec-
tion 4.2.
5. Conclusion
We presented an incremental end-to-end spoken DST frame-
work that generates compact edit operations instead of full be-
lief states, using a multimodal LLM. The incremental formula-
tion provides interpretable updates that significantly outperform
full-state prediction, and GRPO further improves per-turn ac-
curacy by directly optimizing generation-level rewards. Turn-
level analysis showed that the incremental approach consis-
tently outperforms the full-state baseline across all turn ranges.
These results demonstrate that combining incremental state
tracking with reward-driven training is a promising direction for
end-to-end spoken DST.
However, several limitations remain. First, our oracle vs.
predicted evaluation revealed a substantial performance gap
(approximately 40 JGA points), indicating that error propaga-
tion across turns remains a major challenge for the incremental
approach. Since both SFT and GRPO are trained with ground-
truth previous states, the model has limited exposure to the
noisy, error-containing states it encounters during predicted-
mode inference. Second, GRPO requires sampling multiple
candidate generations per prompt during training, which sub-
stantially increases computational cost compared to SFT alone.
Finally, our evaluation was conducted with a single model
(Qwen2.5-Omni-7B) on a single dataset (SpokenWOZ); gener-
alization to other multimodal LLMs, domains, and DST bench-
marks needs further investigation.
A promising direction to address error propagation is train-
ing on dialogues that include erroneous histories—e.g., by in-
jecting predicted states from earlier checkpoints into the train-
ing data—so that the model learns to recover from imperfect
prior states. Other future directions include exploring stream-
ing inference for real-time dialogue applications and a more
thorough exploration of reward design and hyperparameter con-
figurations.
