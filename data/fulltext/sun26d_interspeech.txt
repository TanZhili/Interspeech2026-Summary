Multilingual Speech-to-Text Translation

Abstract
Multilingual S2T models typically use uniform sharing due
to insufficient training data, which can lead to representation
conflicts in low-resource scenarios. We present a gradient-
driven framework that automatically discovers optimal param-
eter sharing configurations by analyzing inter-language gradi-
ent behaviors. Our approach integrates clustering for group-
ing, similarity analysis for shared-private ratios, and joint
SVD with regularized CCA for subspace calibration. On four
low-resource language pairs using the SeamlessM4T-Medium
model, ourGradient-Driven Parameter Sharing (GDPS)
framework achieves consistent improvements.
Index Terms: Multilingual speech translation, Gradient analy-
sis, Parameter sharing, Low-resource languages
1. Introduction
Massively multilingual speech-to-text (S2T) models like Seam-
lessM4T [1, 2], Seamless v2 [3], and MMS [4] utilize uniform
parameter sharing, yet frequently encounter ”negative transfer”
in low-resource settings where gradient conflicts from divergent
tasks degrade convergence.
Gradient conflict is a primary bottleneck in multilin-
gual learning. Optimization methods such as PCGrad [5],
GradOPS [6], and GDOD [7] stabilize training via gradient pro-
jections, while structural strategies like shared-private represen-
tations [8] and task disentangling [9] decouple interfering pa-
rameters. We target FFN2 (the second feed-forward network
within each Conformer block) due to its high parameter den-
sity and non-linear feature transformation role [10], making it
more malleable for language-specific adaptation than attention
modules.
Despite these advances, a significant gap remains: design-
ing optimal parameter sharing configurations is prohibitively
high. Most existing ”shared-private” or ”expert squads” archi-
tectures depend on human intuition or expensive neural archi-
tecture search (NAS) to determine layer-wise configurations.
We propose theGradient-Driven Parameter Sharing
(GDPS) frameworkusing SeamlessM4T’s native support for
our target languages. Our core innovation lies in the transi-
tion from manual parameter sharing design to a fully automated
pipeline:Gradient Analysis→Configuration Generation→
Grouped Fine-tuning. By analyzing inter-language gradient
behaviors using a complementary set of clustering, similarity,
and subspace analysis techniques, our framework automatically
identifies optimal language groups and parameter sharing ratios.
This approach directly addresses three fundamental chal-
lenges in traditional multilingual S2T models:language het-

4. Experiments and results
4.1. Experimental Setup and Training Configuration
We use SeamlessM4T-Medium3 as the backbone model (1.2B
parameters, 12 conformer encoder and decoder layers) based
on the official seamless communication framework. All ex-
periments are conducted on NVIDIA A100 GPUs with mixed-
precision training (FP16) using the AdamW optimizer. Train-
ing hyperparameters are configured as follows: base learning
rateα= 4×10 −5 (group-adjusted:α g = 10−4), batch size
B= 4, dropoutp d = 0.05, weight decayλ= 0.05, random
seeds= 2343, and warmup stepst w = 2000.

4.4. Gradient Representation Alignment Analysis
GDPS significantly enhances cross-lingual alignment compared
to the SeamlessM4T-Med baseline. As shown in Figure 3, av-
erage similarity increases across all languages, with especially
notable gains for Irish (+15.2%) and Bemba (+15.1%), indicat-
ing that shared-private decomposition effectively isolates task
interference. The disproportionate gain for Irish is consistent
with its smallest training corpus (7k lines), where uniform shar-
ing causes the heaviest negative transfer and targeted specializa-
tion yields the largest relative benefit. Overall, GDPS achieves
a +0.085 average similarity increase, validating that automated
grouping and initialization facilitate efficient knowledge trans-
fer.

5. Conclusions
We presentedGDPS, a gradient-driven framework for auto-
mated parameter sharing in low-resource multilingual S2T. By
integrating three complementary gradient analysis techniques,
GDPS achieves consistent gains (up to 3.26% COMET, 14.4%
relative BLEU) over unified fine-tuning, demonstrating that op-
timal sharing configurations can be learned directly from train-
ing dynamics rather than manually designed.
