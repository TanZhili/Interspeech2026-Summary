# 单篇论文技术总结规格

对 batch JSON 里的每一篇，先读 `text_path` 里的全文（参考文献已截掉），再把总结写到 `summary_path`。不要改 batch JSON，不要写别的文件。

全文来自 ISCA PDF 抽取。只写正文里看得到的内容。正文没有的数字、数据集、模块名不要补。正文抽取出乱码时，只总结能读懂的部分，并在点评里说明。

用简体中文，方法名、数据集名、指标名保留英文。

每篇固定结构：

# 论文标题

- 论文编号：
- 报告人：
- 程序：日期 / 会场名
- 技术分类键：
- 全文：PDF 链接

## 问题
这篇论文要解决什么，现有方法差在哪里。

## 方法
把做法讲清楚：输入输出、关键模块、训练目标或推理过程。不要只堆名字。

## 实验与结果
数据、对比对象、正文里给出的主要数字。没有数字就写正文里的定性结果。

## 结论
作者认为做成了什么，边界在哪里（如果正文写了）。

## 点评
一两段技术评论：这个做法抓的是哪一类问题，和常见路线比强在哪、可能脆弱在哪。评论必须能从正文里的设计看出来，不要编造对比实验。
